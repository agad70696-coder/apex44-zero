# Personalized Medicine Forensics

## المشكلة
60% من الأدوية لا تعمل بنفس الكفاءة على كل الناس بسبب الجينات.
دواء آمن لشخص قد يقتل شخص آخر.

## الحل
PersonalizedMedicineEvidence يربط الجين بالدواء
- فحص تفاعلات قاتلة معروفة عالميا (Pharmacogenomics)
- حساب الجرعة حسب الوزن والجين
- أي وصفة قاتلة = is_lethal = True

## مثال حقيقي
طفل مات في أمريكا 2017 لأن الدكتور كتبله كودايين وهو عنده CYP2D6-poor - الكود ده كان هينقذه.

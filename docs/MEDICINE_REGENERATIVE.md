# Regenerative Medicine Forensics

## المشكلة
سوق الأعضاء المزروعة معمليا هيوصل تريليون دولار - ازاي نمنع الغش؟
عضو مزروع ب 10% حيوية ممكن يقتل المريض.

## الحل
RegenerativeEvidence بيسجل كل مرحلة نمو العضو بهاش كمي
- من خلية جذعية -> تمايز -> نضج -> جاهز
- لو عدد الخلايا قل فجأة = تلوث
- لو الحيوية >100% = تزوير بيانات

# Gene Therapy Forensics

## المشكلة
CRISPR ممكن يعالج 7000 مرض وراثي، بس غلطة واحدة في المقص الجيني = سرطان.
شركات ممكن تزور نتائج التعديل.

## الحل
GeneTherapyEvidence بيسجل كل قصّة جينية بهاش كمي
- قائمة جينات ممنوع لمسها (TP53 حارس السرطان)
- أي تعديل خارج المسموح = dangerous
- كل تعديل ليه GRNA وهاش

## استخدام
مستشفيات المستقبل هتستخدمه قبل أي حقنة جينية.
